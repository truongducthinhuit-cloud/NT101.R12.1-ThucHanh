# Lab 01: Mật mã học cổ điển

## Mục tiêu
Tìm hiểu và cài đặt các thuật toán mật mã cổ điển bằng C++.

## Nội dung
- 2.1 Caesar cipher
- 2.2 Mono-alphabetic substitution cipher
- 2.3 Playfair cipher
- 2.4 Vigenère cipher
- 2.6 Phá mã Vigenère (IC + phân tích tần suất)
- 2.7 Rail Fence cipher (mở rộng)

## Hướng dẫn chạy
1. Mở file .cpp bằng Visual Studio (hoặc g++).
2. Biên dịch và chạy (Ctrl+F5).
3. Làm theo hướng dẫn nhập trên màn hình.
